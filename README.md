# Shubham Studio: Client Gallery Platform
A custom-built, full-stack media gallery and portfolio management system developed exclusively for **Shubham Studio (Maa Kalika Creator Lab)**. 
This platform provides a seamless, responsive user interface for showcasing photography and videography services, paired with a secure, custom-built administrative dashboard for effortless content management.

**Developed by:** Pranav Shukla  
**Live Application:** [gallery-client-work.vercel.app](https://gallery-client-work.vercel.app/)

📌 Project Overview
The objective of this project was to deliver a tailored digital storefront for a professional photography studio. It replaces static portfolio pages with a dynamic, easy-to-update system, allowing the client to maintain an up-to-date showcase of their work without requiring any technical knowledge.

Core Features
Dynamic Media Showcases:** Categorized, high-performance galleries for Wedding Photography, Birthday Events, Cinematic Wedding Videos, and Professional Portraits.
Custom Content Management System (CMS):** An authenticated administrative portal that empowers the client to securely upload, categorize, and manage media files directly from the browser.
Responsive User Interface:** Optimized for cross-device compatibility, ensuring high-quality media rendering and fluid navigation across mobile, tablet, and desktop viewports.
Lead Generation Integration:** Direct contact channels strategically placed to facilitate client inquiries and booking requests.

🛠️ Technical Architecture

Frontend Environment:** HTML5, CSS3, Vanilla JavaScript
Backend Runtime:** Node.js with Express.js
Deployment & Hosting:** Vercel
